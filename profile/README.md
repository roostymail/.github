<h3 align="center">Roosty Mail</h3>

<p align="center">
  A lightweight, modern, open-source webmail you host yourself.<br>
  <a href="https://roosty.dev">roosty.dev</a> ·
  <a href="https://github.com/roostymail/roosty">Project</a> ·
  <a href="https://github.com/roostymail/roosty/blob/main/docs/ARCHITECTURE.md">Architecture</a>
</p>

---

Roosty Mail works with any IMAP/SMTP server. It aims to load in under a second, keep your mail safe by default, and let you shape how it looks with ready-made and custom themes.

It is in early development. Feedback and ideas are welcome in the [project issues](https://github.com/roostymail/roosty/issues).
